# 🥽 NMIMS Lift to HPC Lab – VR Application

### 🚀 Explore the HPC Laboratory Through Virtual Reality

Welcome to the **NMIMS Lift to HPC Lab VR Application**! This project aims to provide an immersive Virtual Reality (VR) experience that allows users to explore the journey from a lift to the High-Performance Computing (HPC) Laboratory in a virtual environment.

The application demonstrates how VR technology can be used to create interactive, realistic, and engaging virtual environments for campus navigation and educational purposes.

---

## 📌 About the Project

The NMIMS Lift to HPC Lab VR Application is designed to simulate a virtual journey from the lift to the HPC laboratory at NMIMS.

Instead of relying entirely on physical navigation, users can experience the environment virtually and understand the route to the laboratory through an immersive 3D experience.

This project explores the use of Virtual Reality in educational institutions to improve navigation, visualization, and user experience.

## 🎯 Project Objectives

* 🥽 Create an immersive virtual reality experience.
* 🏢 Simulate the journey from the lift to the HPC laboratory.
* 🧭 Help users understand the laboratory route.

* **🏢 Virtual Environment:** Explore a digitally created campus environment.

## ⚙️ Getting Started

Follow these steps to access the project on your computer.

### Prerequisites

Before starting, make sure you have:

* Unity Hub installed.
* A compatible Unity Editor version.
* Git installed.
* A computer that meets Unity's system requirements.
* Compatible VR hardware, if required by your build.

### 1. Clone the Repository

Open a terminal or command prompt and execute:

```bash
git clone https://github.com/Sricharan-122006/NMIMS-Lift-to-HPC-lab-VR-Application-.git
```

### 2. Open the Project in Unity

1. Open Unity Hub.
2. Select **Add Project** or **Add project from disk**.
3. Browse to the cloned repository folder.
4. Select the project folder.
5. Open it using the compatible Unity Editor version.

### 3. Configure the Project

1. Allow Unity to import the project assets.
2. Open the main scene from the `Assets` directory.
3. Verify the camera, environment, lighting, and navigation setup.
4. Check the XR configuration if the application uses VR hardware.

### 4. Run the Application

1. Open the main scene.
2. Click the **Play** button in Unity.
3. Explore the virtual environment using the configured controls.

For a standalone VR experience, configure the appropriate XR provider and build settings for your target device.

## 🎮 How to Use

1. Launch the application.
2. Enter the virtual environment.
3. Begin exploring from the lift area.
4. Follow the virtual route toward the HPC laboratory.
5. Explore the destination and other available areas.
6. Use the configured controls or VR interactions to navigate.

*The available interactions depend on the implemented features and supported hardware.*

## 🏗️ Project Workflow

The project follows a general VR development workflow:

1. **Environment Design:** Create the virtual lift, corridors, and laboratory surroundings.
2. **3D Development:** Build or import the required environment assets.
3. **Scene Setup:** Arrange the environment, camera, lighting, and navigation elements.

5. **Testing:** Verify navigation, visual quality, and interactions.
